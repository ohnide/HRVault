# HRVault

HRVault é um ERP de Recursos Humanos desenvolvido em .NET 9 utilizando Clean Architecture.

## Tecnologias

- ASP.NET Core 9
- Entity Framework Core
- PostgreSQL
- MediatR
- FluentValidation
- AutoMapper
- ASP.NET Identity
- JWT

## Arquitetura

- HRVault.Api
- HRVault.Application
- HRVault.Domain
- HRVault.Infrastructure
- HRVault.SharedKernel
